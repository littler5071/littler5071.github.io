Rust：最受推崇的語言，卻只有 14.8% 的人在用——我把數據攤開看

Rust 連續多年拿下 Stack Overflow 最受推崇語言（2025 年 72%），實際使用卻只有 14.8%，落差本身就是重點。這篇只擺官方數據：微軟與 Google 都指出約 70% 的嚴重漏洞是記憶體安全問題；Google Android 團隊實測 Rust 的記憶體安全缺陷密度是每百萬行 0.2 個、C/C++ 約 1000 個，差距約 1000 倍，記憶體安全漏洞占比首度降到 20% 以下，回滾率只有 C++ 的四分之一、審查時間少 25%。缺點也照實寫：複雜度被 45.2% 的人列為障礙、導入前 3～6 個月速度下降 30～50%，以及 Rust 自己出過的漏洞（CVE-2025-48530）。最後附一張什麼情況該用／不該用的對照表。
