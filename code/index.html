把重複的電腦操作，變成自己會跑的流程

一套 Windows 自動化工具的功能總覽：錄一次、補上判斷與迴圈，再讓它排程自己跑。「步驟」選單分成四類、共 31 個可以自己加的動作；內建 14 支示範腳本（其中 9 支不需要操作視窗，可以直接用命令列執行）。也一併寫清楚它不適合哪些情況：需要桌面的腳本不能無人值守、找圖對畫面變化敏感、防毒軟體可能誤判。

已上線系列 2／5：基本操作

讓電腦自己動滑鼠、打字，還會在畫面上找按鈕

基本操作類 8 個動作。重點是「找圖點擊」：F12 框選畫面上一塊目標，播放時搜尋到才點，不必知道座標——而且可以跨程式，別的應用程式的按鈕、連 Windows 的開始按鈕都找得到、按得下去。也寫了找圖會壞掉的四種情況，以及什麼時候該用找圖、什麼時候直接用座標。

已上線系列 3／5：變數與流程

從照順序重播，變成會判斷、會重複的流程

變數與流程類 11 個動作。變數可以跨腳本共用（子巨集用同一份，呼叫端可覆寫），修飾詞與預設值讓同一支腳本換個參數就是另一件事；條件判斷除了大小與包含，還能檢查檔案存在、視窗存在、程序執行中。

已上線系列 4／5：系統與檔案

讓腳本去執行別的程式、讀寫檔案、抓下畫面

系統與檔案類 8 個動作。執行外部程式可以等待、取得輸出，並把結束代碼存進變數來判斷成敗；檔案讀寫支援 UTF-8／Big5 與附加模式；螢幕擷取可指定視窗或區域存成 PNG，加上時間戳記就不會覆蓋前一次。

已上線系列 5／5：等待與訊息

等對地方，腳本才換得了電腦

等待與訊息類 4 個動作。核心觀念：能用「等待視窗／等待圖片／等待程序」就不要用固定等待；顯示訊息是唯一真的需要人在旁邊的動作；停止播放可以指定成功或失敗，決定排程看到的結束代碼。

不用寫程式，讓電腦自己批次輸入多筆資料

兩支腳本的實際錄影：一支先在 Excel 裡把整批資料準備好（用「等待視窗」取代固定延遲：開得慢會等、開得快不會多等）；另一支把這些資料批次送進另一個程式，換行時自動回到下一列開頭。同一套迴圈換掉目標程式，就能套用到其他應用程式或網頁表單。附兩支腳本的完整步驟表。
