不用寫程式，讓電腦自己批次輸入多筆資料

兩支腳本的實際錄影：一支先在 Excel 裡把整批資料準備好（用「等待視窗」取代固定延遲：開得慢會等、開得快不會多等）；另一支把這些資料批次送進另一個程式，換行時自動回到下一列開頭。同一套迴圈換掉目標程式，就能套用到其他應用程式或網頁表單。附兩支腳本的完整步驟表。
