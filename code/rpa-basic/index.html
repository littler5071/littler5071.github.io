讓電腦自己開程式、打字，
還會「看畫面」找按鈕點下去

一支示範腳本：啟動記事本、輸入文字、全選複製、存成變數，最後不用座標就點到粗體鈕
2026/10/01・系列 2／5：基本操作
這支示範的是最基本的一條路線：讓電腦自己去啟動程式、敲鍵盤、打字、複製， 最後把複製到的內容存成變數。整支腳本從頭到尾沒有人碰鍵盤滑鼠。

啟動程式、等待視窗出現

影片裡的做法：第一個動作是啟動 notepad.exe，第二個動作是 等待「記事本」視窗出現。等視窗比硬等固定秒數可靠——程式還沒開好就繼續下一步， 常常會把字打到不對的地方；等視窗是「真的看到它了才往下走」。

文字輸入與鍵盤：中文也沒問題

影片裡的做法：程式自己把三段文字打進記事本，包含中文與數字。 文字輸入支援中文與多行，換行會自動轉成 Enter；連續打字在錄製時會合併成一個步驟。
少數程式對「直接注入文字」不理會時，設定裡可以改成用剪貼簿貼上或逐鍵掃描碼； 中文輸入法干擾的話，有一個「播放前自動切換輸入法為英文」的選項。

組合鍵與變數：把結果留下來

影片裡的做法：用 Ctrl+A 全選、Ctrl+C 複製，把選到的內容放進剪貼簿， 再把複製到的內容存成一個變數。之後任何一步驟要用，隨時可以拿出來。
組合鍵（例如 Ctrl+Shift+End）就是「按下、放開」的序列， 所以 Ctrl+A 這種動作會拆成三個鍵盤步驟記錄下來。

找圖點擊：不知道座標也能點到按鈕

影片裡的做法：文字全選之後，腳本拿「工具列上那個粗體鈕」的畫面， 去整個畫面裡比對，找到就直接點下去——全程沒有輸入任何滑鼠座標。 點完之後你會看到整段文字真的變粗。

什麼時候該用找圖？當目標的位置是程式事先不知道的時候。像是 位置會移動的面板、隨視窗大小改變的按鈕、別的程式裡的元素—— 這些用死座標點，換一台電腦、視窗拉大一點就點錯了。
找圖的作法是：先 F12 框選畫面上的目標存成樣板，播放時拿樣板去比對整個畫面。 容差控制要多像才算同一個目標（太小找不到、太大會點錯，建議 20～40）； 搜尋區域可以限定只在某個範圍裡找，速度更快也避免點到相似的錯誤目標。
容差與搜尋區域這兩個參數，示範腳本裡都設定好了： 你在影片裡看到它一次就找成功，就是因為限定了搜尋範圍、又把容差收到 12。
