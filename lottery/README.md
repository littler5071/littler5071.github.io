# LUCKY DRAW · 員工大會抽獎系統

一套給 **100～300 人實體活動**（員工大會、尾牙、發表會）使用的抽獎系統。
純 HTML/CSS/JS，**不需安裝、不需網路、不需後端**，雙擊即可上場。

- 操作台（筆電）＋ 舞台畫面（大投影機）雙視窗
- 高張力動畫：聚光蓄勢 → 高速翻牌 → 假動作回馬槍 → 光爆彩帶
- 每人最多中獎一次，抽獎結果以控制台為準，投影畫面只負責演出
- 完整中獎紀錄、撤銷、CSV 匯出、JSON 備份

---

## 一、30 秒開始

1. 雙擊 `index.html`（或 `開啟抽獎系統.bat`）。
2. 右上角按 **開啟投影畫面** → 把新視窗拖到投影螢幕。
3. 在投影視窗點一下畫面「**點擊啟動舞台**」（啟用音效＋全螢幕）。
4. 左側「員工名單」→ **範例名單**（試玩）或 **貼上名單 / 匯入 CSV**。
5. 按 **Enter** 開始抽獎。

> 第一次使用建議先跑一次「範例名單」，確認投影機、音量、字體大小。

## 二、現場設定（活動前 10 分鐘）

| 步驟 | 動作 | 說明 |
|---|---|---|
| 1 | Windows：`Win + P` → **延伸** | 筆電與投影機分開顯示 |
| 2 | 控制台按「開啟投影畫面」 | 新視窗拖到投影螢幕 |
| 3 | 投影視窗點擊啟動 | 啟用音效、進入全螢幕（或按 `F`） |
| 4 | 控制台按「測試投影」 | 確認閃光與音效正常 |
| 5 | 設定 → 調整「抽獎節奏」 | 建議 4.0～5.0 秒，头奖会自动加长 |

**音效一定要先點過投影畫面**，否則瀏覽器會阻擋自動播放（畫面動畫不受影響）。

## 三、操作說明

### 抽獎
- 上方籌碼列選擇獎項（例：參加獎 → 三獎 → 二獎 → 頭獎）。
- **切換獎項時，「抽出人數」會自動帶入該獎項的剩餘名額**（同時不超過目前候選人數），
  按鈕上會顯示「開始抽獎 · N 名」；再點同一個獎項不會覆蓋你手動改過的數字。
- 按 **開始抽獎** 或 **Enter**。
- 抽完一輪後人數回到 1，按下一張籌碼換獎項。流程由主持人掌控，不會自動跳轉。

### 臨時加碼
- **＋ 臨時加碼**：建立新獎項（名稱／名額／視覺等級），適合長官現場加碼。
- **加抽 1 名**：在目前獎項再多抽一位（會顯示 `3/1` 超額狀態，屬正常）。

### 出錯處理
- **撤銷上一輪**（`Ctrl + Z`）：整輪退回，中獎者回到候選池。
- 中獎紀錄每一輪右側也有「撤銷」。
- **重設本獎項**：清空該獎項的所有中獎紀錄。
- **黑屏／音樂**：`B` 投影黑屏以便中場談話；`M` 或右上「♪ 音樂」開關背景音樂。
  抽獎開始時音樂會**自動停止**；**這一輪結束後會自動接回並持續循環播放**（不需要手動按）。

### 匯出
- 中獎紀錄 → **匯出 CSV**（Excel 可直接開啟，含 BOM 不亂碼）。
- 設定 → **匯出備份**：完整 JSON（名單＋獎項＋紀錄），可換電腦還原。

## 四、名單格式

支援 **CSV 檔** 或 **直接從 Excel 複製貼上**（Tab 分隔）。

```
姓名,部門,員工編號
王小明,業務部,A001
陳美玲,研發部,A002
```

- 欄位順序：`姓名`、`部門`、`員工編號`（後兩欄可省略）。
- 有表頭會自動辨識（姓名／部門／編號／name／dept…）。
- CSV 若為 Excel 預設的 Big5 編碼也能自動判讀。
- **.xlsx 請先另存 CSV**，或直接在 Excel 選取儲存格複製貼上。
- 同名同部門會自動加序號區分；員工編號相同視為同一人。
- 可個別勾選「排除」（例：已離職、不在場），排除者不進候選池。

## 五、快捷鍵

| 按鍵 | 功能 |
|---|---|
| `Enter` / `Space` | 開始抽獎 |
| `Ctrl + Z` | 撤銷上一輪 |
| `S` | 開啟投影畫面 |
| `B` | 投影黑屏／恢復 |
| `M` | 背景音樂開／關 |
| `F`（投影視窗） | 全螢幕切換 |
| `Esc` | 關閉彈窗 |

## 七、疑難排解

| 症状 | 處理 |
|---|---|
| 按「開啟投影畫面」沒反應 | 瀏覽器封鎖彈出視窗 → 允許此頁面的彈出視窗 |
| 投影畫面顯示「未連線」 | 關閉投影視窗，重新按「開啟投影畫面」 |
| 沒有聲音 | 在投影視窗點一下畫面；確認系統音量與「設定 → 音效」開啟 |
| 字太小／太大 | 投影視窗按 `F` 全螢幕；名字會依長度自動縮放 |
| 抽錯人 | `Ctrl + Z` 撤銷該輪後重抽 |
| 資料不見了 | 重新整理不會清除（存在 localStorage）；換電腦請用備份 JSON |
| 換瀏覽器／換電腦 | 用「匯出備份 / 匯入備份」搬移 |

> 建議活動前一天用**同一台筆電、同一個瀏覽器**完整彩排一次。

## 八、已知限制

- 資料存在瀏覽器 localStorage（同一個瀏覽器、同一個檔案路徑）。清除瀏覽器資料會遺失，重要活動請先匯出備份。
- 不使用網路，因此不支援「多台裝置同時抽獎」或即時連線投票；同名單可在多台電腦各自匯入。
- 舞台音效由投影視窗播放；若筆電接耳機而投影機走 HDMI，請確認音訊輸出裝置。
- 投影畫面與控制台必須由控制台開啟（同一個瀏覽器視窗群），跨瀏覽器無法連線。
